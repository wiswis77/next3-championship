# 단계별 진행 규칙 (AI Championship 2026)

이 문서는 **에이전트와 사용자 사이의 운영 룰**이다.  
구현·검색·판단은 에이전트가 하고, 사용자는 **큰 그림 + 확인이 필요한 결정만** 한다.

## 역할

| 역할 | 담당 |
|------|------|
| 조사·비교·설계·구현·배포·문서 초안 | 에이전트 |
| 단계 완료 여부 확인, 갈림길 선택 | 사용자 |
| 제출·발표 스토리의 최종 톤 | 사용자 확인 후 확정 |

## 단계 문서 규칙

1. 모든 단계는 `docs/championship/stages/` 아래 `NN-이름.md`로 남긴다.
2. 각 단계 문서는 최소 아래 섹션을 가진다.
   - **목표**
   - **결정 사항** (확정 / 보류)
   - **산출물**
   - **사용자 확인 포인트** (있으면)
   - **다음 단계**
3. 단계가 끝나면 문서 상단 `status`를 `done`으로 바꾸고, `INDEX.md`를 갱신한다.
4. 코드를 크게 바꾸기 전에 **해당 단계 md에 의도**를 먼저 적는다. (사후 설명만 쓰지 않는다)
5. 번복이 필요하면 새 단계로 `NN-revision-...`를 추가하고, 이전 문서는 지우지 않는다. (히스토리 보존)

## 품질 기준 (본 프로젝트)

- **병목 각성:** “그런 불편이 있었네 / 내 얘기네”
- **해결 WOW:** “그걸 이렇게 자르네?”
- **유려함:** 기능 추가보다 절제. 틀린 확정 < 정직한 ‘확인 필요’
- **AI 포인트:** 독해 대행이 아니라 **행동 추출**
- **해커톤:** 작동 링크 + 짧은 데모 + 제출 설명

## 사용자 확인이 필요한 때

- 제품 한 줄 정의 / 범위 in·out
- 외부 유료 API·계정·배포 대상
- 법적·의료·금융처럼 책임 문구
- “이 단계 done으로 볼까?” 명시적 사인오프

그 외 구현 세부·파일 구조·카피 초안은 에이전트가 진행하고, 단계 md에 기록한다.
